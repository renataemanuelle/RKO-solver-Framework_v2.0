--- Notes ---

- The RKO framework uses OpenMP parallelism with 10 concurrent metaheuristics.
  Each metaheuristic runs on its own thread, sharing a solution pool via
  #pragma omp critical sections.

- Thread reproducibility limitation: despite using fixed seeds per run,
  OpenMP thread scheduling introduces non-determinism in pool access order.
  Results may vary slightly between runs with the same seed.
  (See dissertation discussion on parallelism and reproducibility.)

- No swap partition was configured. With 16 GB RAM the AEOSSP instances
  (up to ~6000 acquisitions) fit comfortably in memory.
